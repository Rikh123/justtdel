# Getting Started with Create React App

Welcome to the **Create React App** project, bootstrapped with [Create React App](https://github.com/facebook/create-react-app). This tool helps you build and manage modern React applications.

## Available Scripts

In the project directory, you can use the following commands:

### `npm start`

Start the app in development mode.  
Visit [http://localhost:3000](http://localhost:3000) to view it in your browser.

- The page will automatically reload when you make changes.
- Any linting errors will be displayed in the console.

### `npm test`

Launch the test runner in interactive watch mode.  
To learn more about testing with Create React App, refer to the [Testing Docs](https://facebook.github.io/create-react-app/docs/running-tests).

### `npm run build`

Create an optimized production build in the `build` folder.

- This bundles and minifies your React app for better performance.
- The filenames will include hashes to optimize caching.

Your app is now ready to be deployed!  
To learn about deploying your app, visit the [Deployment Docs](https://facebook.github.io/create-react-app/docs/deployment).

### `npm run eject`

**Warning:** This is a one-way operation. Once you eject, you cannot go back!

- If you need to customize the build configuration (e.g., webpack, Babel, ESLint), you can run this command.
- After ejecting, you’ll have full control over the configuration, but it’s not recommended unless necessary.
